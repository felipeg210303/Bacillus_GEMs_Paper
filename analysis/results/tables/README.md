# analysis/results/tables/

Generated summary tables, one table per CSV.

| File | Produced by |
|---|---|
| `Score.csv` | `01` - feature counts, MEMOTE score, biomass MW per model |
| `Network_Topology.csv` | hand-compiled from the MEMOTE reports in `../reports/` (no notebook) |
| `SBO_Reaction_Matrix.csv` | `02` - reaction counts per SBO term per model |
| `Chubukov_2013_results.csv`, `Dauner_2001_results.csv`, `Dauner_2001caa3KO_results.csv` | `03` - simulated vs. experimental growth |
| `*_metrics.csv` | `04` - CCC/RMSE/MAE/Bias per model for each experiment |
| `PhPP.csv` | `05` - glucose uptake vs. growth rate |
| `GeneEssentiality.csv` | `06` - confusion matrix and classification metrics per model |
| `carbon_metabolism_fluxes.csv` | `07` - flux per reaction per model, with the measured value |
| `carbon_utilization_Summary.csv`, `carbon_utilization_Per_Substrate_Outcomes.csv` | `08` |
| `PhPP_3D_grid.csv` | `09` - the full glucose x oxygen growth grid |
