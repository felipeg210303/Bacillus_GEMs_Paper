# analysis/results/

Everything the notebooks generate. Safe to delete and regenerate by re-running the pipeline, but be careful because `reports/` takes a long time to rebuild (MEMOTE runs a full test suite per model).

- `figures/` - plots, included directly by the manuscript and supplementary LaTeX.
- `tables/` - summary tables, all CSV.
- `reports/` - MEMOTE quality reports, one HTML per model.
