# 3d_PhPP/

Two-substrate phenotype phase planes from `05_phenotype_phase_plane.ipynb`: growth rate as a
surface over glucose x oxygen uptake, on M9 minimal medium.

- `PhPP_3D_<model>.pdf` - one 3D surface per model, each on its own growth-rate scale, annotated
  with its line of optimality and the M9 operating point.
- `PhPP_3D_all_models.pdf` - all models as small multiples on a shared scale (surfaces only).
- `PhPP_contour_all_models.pdf` - the same surfaces seen from above, with the line of optimality,
  the zero-growth boundary and the M9 point marked. This is the panel to read phase regions from.
