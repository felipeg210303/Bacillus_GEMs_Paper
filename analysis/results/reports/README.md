# analysis/results/reports/

MEMOTE snapshot reports, one self-contained HTML per model, generated by
`01_feature_count_memote_score.ipynb`. Open one in a browser for the full per-test breakdown
behind the single quality score recorded in `../tables/Score.csv`.

Regenerating these is the slowest step in the pipeline (a full MEMOTE test suite per model), so
notebook `01` is normally left alone unless the models themselves change.
